# Fablab Stock : guide des enseignants

Fablab Stock sert à savoir ce qu'il reste de filament et de plaques, et à noter ce que chacun prélève.
Il s'utilise sur téléphone dans l'atelier, ou sur PC.

## Entrer dans l'application

1. Ouvrez l'adresse de l'application, ou scannez le QR code affiché au fablab.
2. Saisissez le **code d'accès** communiqué par le gestionnaire.

Le code n'est demandé qu'une fois par appareil. Il sera redemandé si le gestionnaire le change, ou
après trois mois sans utilisation.

Après cinq codes faux, l'appareil est bloqué un quart d'heure : attendez, puis réessayez.

## Installer l'application sur son téléphone

- **Android (Chrome)** : menu ⋮, puis « Ajouter à l'écran d'accueil ».
- **iPhone (Safari)** : bouton Partager, puis « Sur l'écran d'accueil ».

L'application a besoin d'une connexion internet pour fonctionner.

## Voir le stock

L'écran **Stock** présente le fablab comme un rayonnage : une étagère pour le filament, une pour
les plaques, et un casier par matière.

- Le grand chiffre est le nombre de bobines ou de plaques entières restantes.
- **✓ EN STOCK** : tout va bien.
- **! À COMMANDER** : le stock est bas, la matière figure dans la liste à commander.
- Les boutons **Tout / Filament / Plaques** et « Recherche et filtres » réduisent l'affichage.
- Le bouton **Liste** remplace les casiers par un tableau que l'on peut trier.

## Prélever une bobine ou une plaque

1. Touchez le casier de la matière (ou passez par **Prélever** et choisissez-la dans la liste).
2. Choisissez **votre nom**. Il est retenu sur l'appareil pour la fois suivante.
3. Réglez la **quantité** avec les boutons − et +.
4. Choisissez la **machine**.
5. Indiquez le **projet ou la classe**. Des propositions apparaissent d'après les saisies précédentes :
   reprenez-les pour éviter les variantes d'écriture.
6. Ajoutez un commentaire si besoin, puis touchez **Valider le prélèvement**.

Le nouveau stock s'affiche. Si la quantité demandée dépasse le stock, la validation est bloquée.

On compte en bobines entières et en plaques entières : une bobine entamée mais remise en place ne se
note pas.

## Noter une livraison

Écran **Prélever**, bouton **Entrée de stock** : choisissez la matière, votre nom, la quantité reçue,
et éventuellement le numéro du bon de livraison en commentaire.

## Corriger une erreur

Un mouvement ne se modifie pas : il s'annule, puis se ressaisit.

- **Tout de suite après la saisie** : bouton « Annuler ce prélèvement » sur l'écran de confirmation.
- **Plus tard** : écran **Historique**, bouton **Annuler** sur la ligne concernée.

Vous ne pouvez annuler que le **dernier mouvement** d'une matière, et dans les **24 heures**. Si
quelqu'un d'autre a prélevé la même matière entre-temps, ou si le délai est passé, adressez-vous au
gestionnaire.

L'annulation reste visible dans l'historique, avec le nom de la personne qui a annulé.

## Consulter l'historique

L'écran **Historique** liste tous les mouvements, du plus récent au plus ancien. Les filtres
permettent de retrouver les prélèvements d'une classe, d'une machine, d'un collègue ou d'une période.
Le bouton **Exporter en CSV** produit un fichier qui s'ouvre directement dans Excel.

## Voir ce qu'il faut commander

L'écran **À commander** liste les matières dont le stock est bas, avec une quantité suggérée. La
pastille rouge de la navigation indique combien de matières sont concernées. La liste s'imprime ou
s'exporte ; c'est le gestionnaire qui passe les commandes.

## Messages que vous pouvez rencontrer

| Message | Que faire |
|---|---|
| « Stock insuffisant : il reste N… » | Quelqu'un a prélevé entre-temps. Réduisez la quantité. |
| « Trop d'essais. Réessayez dans N minutes. » | Attendez le délai indiqué avant de ressaisir le code. |
| « Votre session a pris fin. » | Ressaisissez le code d'accès. |
| « Ce nom n'est plus dans la liste des enseignants. » | Choisissez votre nom ; s'il manque, voyez le gestionnaire. |
| « Le serveur ne répond pas. » | Vérifiez la connexion internet du téléphone. |

Votre nom ne figure pas dans la liste, une matière manque, un stock affiché est faux : prévenez le
gestionnaire du fablab.
